# 🎬 Movie & Series Catalog

Movie and Series Catalog Project with React  
This project's main objective is the development of a web application for displaying movies and series using the React library. The initiative aims to enhance my knowledge of React.

## About the Project

A modern web application built with **React and CSS** that connects to **The Movie DB (TMDB)** API to display comprehensive information about movies and TV series. The project focuses on creating an intuitive user interface for browsing and discovering entertainment content.

## Features

- 🎭 **Browse Movies & TV Shows** - Explore vast collection of films and series
- ⭐ **Rating System** - View audience scores and reviews
- 🎬 **Detailed Information** - Cast, synopsis, trailers, and more

## API Integration

This project integrates with **The Movie DB (TMDB) API** to fetch:
- Movie and TV show data
- Cast and crew information
- Images and posters
- Ratings and reviews
- Trailers and videos
